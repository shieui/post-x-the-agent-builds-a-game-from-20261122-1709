# The one prompt

Build a tiny browser game: a one-button catch game called "Star Catcher".
Colourful stars fall from the top of the screen; the player slides a basket
left and right with the arrow keys (or A/D, or by dragging) and catches stars
for points. Catching a star scores 10, a rare pink star scores 25, missing a
star costs one of three lives. 60 seconds on the clock, big score at the top,
a start screen and a game-over screen showing the final score. Make it
bright, chunky and instantly playable in a single HTML page.
